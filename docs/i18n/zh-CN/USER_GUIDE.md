# Bookmark X 用户指南

[English](../../../README.md) · **简体中文** · [其他语言](../README.md)

Bookmark X 是一款开源 Chrome 扩展，无需使用 X API 即可抓取您的 X 书签。
数据保存在当前 Chrome 配置文件中，并可导出为 TXT、Markdown 或 JSON 备份。

## 安装或更新

1. [下载已构建的 ZIP](https://github.com/LucasDitchun/export-bookmarks-x-twitter/releases/latest/download/bookmark-x.zip)，并解压到一个长期保留的文件夹。
2. 打开 `chrome://extensions`，启用**开发者模式**，然后选择**加载已解压的扩展程序**。
3. 选择包含 `manifest.json` 的文件夹。
4. 更新时，用新版本替换文件，然后在扩展卡片上点击**重新加载**。本地数据会保留。

需要 Google Chrome 116 或更高版本。

## 抓取书签

打开 `https://x.com/i/bookmarks`，等待列表显示，然后打开扩展。**最近**只查找新项目；
连续遇到设置数量的已知书签后会停止。**全部**检查整个列表，并同步在其他设备上
删除的项目。首次抓取始终为完整检查。处理期间请保持 X 标签页打开。

## 笔记、标签和文件夹

保存帖子后，Bookmark X 可以打开对话框，让您添加私人笔记、标签和文件夹。
这些信息只保存在浏览器中。在“书签库”中可以搜索、编辑笔记和整理帖子。
文件夹支持子文件夹；标签可用于跨文件夹分类。

## 导出与备份

书签库可导出为 TXT 或 Markdown，并可按文件夹及其子文件夹、多个标签或已归档帖子筛选。
在**设置 → 导出**中选择要包含的字段。

**备份与恢复**会下载完整 JSON。选择**合并**可保留本地数据；选择**替换**则只使用备份。
备份可能包含私人笔记，请妥善保管。

## 搜索与隐私

文本搜索完全在本地运行。语义搜索为可选功能：只有得到您的同意后才会下载模型，
索引和查询均留在设备上。扩展没有服务器、广告、分析或遥测功能。

## 故障排除

- **页面未准备好：**确认当前标签页为 `x.com/i/bookmarks`。
- **抓取似乎停止：**X 可能仍在加载，请等待状态提示。
- **扩展未更新：**打开 `chrome://extensions` 并点击**重新加载**。
- **清除数据或重新安装前：**先创建 JSON 备份。
